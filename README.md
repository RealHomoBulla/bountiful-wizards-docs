# Почта владельца

## Читать с телефона

**[Bountiful Vault](https://bountiful-vault.daedromans.chatgpt.site)** — приватная Obsidian-подобная
читалка этой папки с деревом, рабочими внутренними ссылками и полнотекстовым поиском. Она читает
актуальную ветку `main` прямо из GitHub: после обычного `push` достаточно обновить страницу;
перепубликовывать Site не нужно. Вход — через тот же аккаунт ChatGPT. `backups/` и
`shader_profiles/` намеренно не показываются.

Это папка только для того, что владельцу действительно нужно прочитать или открыть руками.
Подробные рабочие материалы лежат в [`agents/`](agents/), завершённые и заменённые — в
[`archive/`](archive/). Правило поддержания папки закреплено в [`../AGENTS.md`](../AGENTS.md).

## Как устроена папка

- Корневые страницы выше — постоянные, без дат; агенты переписывают их на месте.
- `agents/state/` и `agents/registers/` — полный handover, OPEN и TODO для агентов.
- Остальные `agents/<тема>/` — актуальные подробные исследования, планы и отчёты.
- `archive/<тема>/` — завершённые или заменённые материалы; они сохранены для истории.
- `backups/` и `shader_profiles/` — служебные данные, не входящая почта.

Если в корне появляется датированный отчёт, сырой реестр, prompt или агентский аудит, он лежит не
там и должен быть перенесён в `agents/` либо `archive/`.
