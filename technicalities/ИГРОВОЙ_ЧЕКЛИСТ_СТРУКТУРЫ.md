# Чеклист осмотра структур

Отметка `☐ → ☑` здесь означает только: структура увидена в игре. Решение о её луте остаётся в `OPEN.md`, §1.248, вопрос L2; этот файл собирает команды и наблюдаемые основания, а не хранит решение.

## ☐ BOMD — Obsidilith Arena

**Лут по аудиту:** 140.055 сырого награждения из сундука.

**ID структуры:** `bosses_of_mass_destruction:obsidilith_arena`.

**Измерение:** Край (`minecraft:the_end`).

**Команды:**

```mcfunction
/execute in minecraft:the_end run locate structure bosses_of_mass_destruction:obsidilith_arena
/execute in minecraft:the_end run tp @s <X_из_locate> <Y_для_арены> <Z_из_locate>
/execute in minecraft:overworld run tp @s <X_дома> <Y_дома> <Z_дома>
```

**Смотреть:** арена начинается на Y=90; проверьте, есть ли обязательный бой с боссом и открывается ли сундук только после него.

## ☐ Twilight Forest — Fancy Well

**Лут по аудиту:** 47.708 сырого награждения.

**ID структуры:** отсутствует: в jar нет `worldgen/structure/fancy_well.json`; это configured feature `twilightforest:fancy_well`, а не структура реестра.

**Измерение:** Сумеречный лес (`twilightforest:twilight_forest`).

**Команды:** `/locate structure` здесь не сработает, потому что это feature. Ближайшая рабочая альтернатива — создать её командой в измерении:

```mcfunction
/execute in twilightforest:twilight_forest run tp @s <X_для_осмотра> <Y_для_поверхности> <Z_для_осмотра>
/execute in twilightforest:twilight_forest run place feature twilightforest:fancy_well <X_для_осмотра> <Y_для_поверхности> <Z_для_осмотра>
/execute in minecraft:overworld run tp @s <X_дома> <Y_дома> <Z_дома>
```

**Смотреть:** это поверхностный колодец; проверьте, охраняется ли он, требует ли доступ/головоломку и лежит ли сундук сразу в открытом месте.

## ☐ IDAS — Archmage Tower и Dread Citadel

**Лут по аудиту:** целевые таблицы сундуков не регистрируются, поэтому намеренная награда сейчас отсутствует.

**ID структур:** `idas:ars_nouveau/archmages_tower`; `idas:iceandfire/dread_citadel`.

**Измерение:** Верхний мир (`minecraft:overworld`): Archmage — леса/равнины/луга; Dread Citadel — снежные леса, снежные равнины и ледяные биомы.

**Команды:** сначала используйте целевые ID. Их JSON помечены `optional_dependency_structure` и требуют соответственно `ars_nouveau` и `iceandfire`; если игра ответит, что структуру найти нельзя, ближайшие рабочие аналоги IDAS — `idas:wizard_tower` и `idas:tinkers_citadel`.

```mcfunction
/locate structure idas:ars_nouveau/archmages_tower
/locate structure idas:iceandfire/dread_citadel
/tp @s <X_из_locate_нужной_структуры> <Y_для_входа> <Z_из_locate_нужной_структуры>
/execute in minecraft:overworld run tp @s <X_дома> <Y_дома> <Z_дома>

# Если целевой /locate сообщил, что структуру найти нельзя:
/locate structure idas:wizard_tower
/locate structure idas:tinkers_citadel
/tp @s <X_из_locate> <Y_для_входа> <Z_из_locate>
/execute in minecraft:overworld run tp @s <X_дома> <Y_дома> <Z_дома>
```

**Смотреть:** у доступных аналогов оцените высоту/размер, плотность мобов и находится ли сундук за зачисткой; это только ориентир, не подмена отключённых Archmage/Dread.
