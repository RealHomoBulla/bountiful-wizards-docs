## Galosphere: руда и серебро — вердикт по аудиту орегена (2026-09-01)

**Вывод: в мастере ничего не останавливало генерацию руды — и теперь останавливает.** Аудит доказал,
что живой вектор руды это не очевидные `ore_palladium_*` фичи (они сироты, любой оверрайд по ним —
пустышка), а два biome-modifier'а: `add_silver_ores` 90 блоков/чанк по всему оверворлду и
`add_large_silver_ores` 192/чанк в crystal_canyons. Плюс второй, независимый генератор — жила
AdLods palladium — и третий источник, `pillagerDropPalladiumNugget=true`, чей конфиг
`galosphere-common.toml` в мастере вообще не существовал. До `003afb1` руду прятал только Block Swap,
у которого дефектный retro-путь.

**Что сделано:** оба biome-modifier'а перекрыты, AdLods-жила выключена, конфиг заведён в мастер,
pillager-нуггет выключен, мёртвые `silver_*` id починены в loot. `index_world_data.py` показывает
0 блоков/чанк по обоим. MASTER = SERVER = MAIN по всем 12 файлам.

**Что осталось на тебя:** 1) приёмка в игре — новый чанк не должен родить `galosphere:palladium_ore`,
старый чанк проверить отдельно (Block Swap не гарантирует чистку уже сохранённой руды); 2) новое
решение **§1.383** — аддон `galosphere_spellbooks` 1.1.1 полностью сломан против Galosphere 1.5.2
(7 рецептов + тег + материал брони), KubeJS его не чинит: снять джарник (рекомендация), переписать
7 рецептов, или жить с 7 ошибками в каждом логе.

Отчёт: `claudework/agents/worldgen/2026_09_01_GALOSPHERE_ORE_MUST_NOT_REMAIN_AUDIT.md`.

## 02.09 · Wheels Upon Chairs — разбор готов, одна поломка уже закрыта

`claudework/agents/mods/2026_09_01_CREATE_WHEELS_UPON_CHAIRS_JAR_TRIAGE.md`. Читали байткод, не
описание мода. 63 миксина, папки `data/` нет вообще — значит ни один рецепт, лут или тег он
датапаком тронуть не может. Зависимость `create [6.0.8,)` при установленном ровно 6.0.8, MIT.

**Что он даёт:** тринадцать бэкпортов настоящих багфиксов Create с номерами PR. Среди них удаление
жидкости под полной помпой и дедлок железнодорожного сигнала — это тихие потери, худший тип бага для
торговой экономики. Поэтому вердикт **оставить, но с конфигом**; снимать не за что.

🔴 **Где он вредил — и вредил прямо сейчас.** `easy_belt` включён по умолчанию, и мод вписывает ±256
(максимум скорости ленты Create) в каждую ленту в момент установки. То есть любая поставленная лента
ехала на полной скорости **без вала, без напряжения и без SU**. Конфига мода не существовало ни на
одной стороне, так что пак жил на этом дефолте. Я перепроверил по байткоду сам, прежде чем что-то
менять.

✅ **Закрыл ночью:** `config/createwheelsuponchairs-common.toml` с одной строкой `easy_belt = false` —
мастер, живой клиент, живой сервер, одинаковый SHA-256 во всех трёх. Одна строка, потому что это
единственная опция, которую выключает **любой** вариант твоего решения; всё остальное — твоё.

**Что осталось на тебя — буква в `OPEN.md` §1.388:** A оставить с полным конфигом (рекомендация),
B оставить только багфиксы, C снять джарник. Мод пока в карантине.
