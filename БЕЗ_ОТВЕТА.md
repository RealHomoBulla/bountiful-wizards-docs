## Как это поддерживается

Прогон делает продюсер — **перед компактингом, перед хендовером и на 90 % контекста**,
то есть в тех же трёх точках, где он и так обязан спасать состояние. Автоматом это не
делается намеренно: понять, ответило ли сообщение на вопрос, — суждение, а не регулярка.
Гарантируется здесь другое — что **после** прогона результат переживёт сессию.

Строка заводится так:

```powershell
python bountiful_wizards_REMAKE/tools/unanswered.py add \
    --question "..." --blocks "..." --cost "..." --priority P1
```

Закрывается — с указанием, чем именно:

```powershell
python bountiful_wizards_REMAKE/tools/unanswered.py close --id U001 --reason "..."
python bountiful_wizards_REMAKE/tools/unanswered.py close --id U002 --stale --reason "..."
```
