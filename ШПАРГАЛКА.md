# Шпаргалка — команды, которые реально пригождаются

Заведена 19.09 по твоей просьбе («запиши мне куда-то отдельно в мои cheatsheets»). Сюда попадает
только то, что мы **проверили в живой игре или вычитали из джарника** — не из вики и не по памяти.
Одна строка — одно дело.

## Поиск в EMI

- `#bountiful_wizards:artifacts_and_relics` — все артефакты и реликвии пака одним запросом.
- `#forge:ores/copper` — любой тег так же: решётка плюс путь тега.
- `@create` — всё, что добавил мод, по его modId.
- `$tools` — по категории предметов.

## Найти место

- `/locate biome minecraft:jagged_peaks` → координаты, потом `/tp @s <x> 120 <z>`.
- `/locate structure repurposed_structures:mansion_oak` — то же для структур.
- `/lods locate_nearest_deposit diamond` — **ближайший СГЕНЕРИРОВАННЫЙ депозит AdLods**, с кликабельным
  телепортом. Имена — как файлы в `bountiful_wizards_REMAKE/config/adlods/Deposits/`: diamond, emerald, gold, iron, copper,
  coal, silver, uranium, ancient_debris, amethyst…
- `/lods list_generated_around 200` — что уже сгенерировалось вокруг.
- `/chunky radius 2000` + `/chunky start` — пререндер, если надо чтобы мир «появился» заранее.

## Посчитать руду за 10 секунд

- `/fill ~-15 <Y> ~-15 ~16 <Y+31> ~16 air replace <id_руды>` — куб 32×32×32 (предел команды),
  в чате печатается «filled **N** blocks» — это и есть счётчик.
- ⚠️ Команда **уничтожает** посчитанное. Только в тестовом мире.
- ⚠️ Ниже Y≈0 камень сланцевый: считать надо `deepslate_*_ore`, обычная руда там не встречается.

## Другие измерения

- `/execute in deeperdarker:otherside run tp @s 0 40 0` — вход куда угодно без портала.
- `/execute in minecraft:overworld run tp @s <x> <y> <z>` — обратно.
- ⚠️ `/locate` ищет по **текущему** измерению — сперва телепорт, потом поиск.

## Поставить фичу принудительно

- `/place feature bw_lode:motherlode_diamond ~ ~ ~` — не ждать редкой генерации, а положить рядом.
- `/place feature minecraft:amethyst_geode ~ ~ ~` — так же с жеодой.

## Мобы и ворота

- `/summon minecraft:skeleton ~ ~1 ~3` — пресеты Mobbility применяются **и к summon** (проверено).
- `/execute as @e[type=minecraft:skeleton,distance=..20] run data get entity @s HandItems[0].id`
  — посмотреть, что у всех в руках, одной командой.
- `/open_gateway ~ ~ ~ gateways:overworldian_nights` — вызвать ворота на месте.
- `/open_gateway @s gateways:overworldian_nights` — то же, но на игроке.
  ⚠️ **Третьего аргумента у команды нет.** Прежняя запись `~ ~ ~ … @s` не парсится — ты на неё уже
  напоролся 20.09. У мода две ветки по ДВА аргумента: `<позиция> <тип>` **или** `<сущность> <тип>`
  (`GatewayCommand.class`, проверено по джарнику `GatewaysToEternity-1.20.1-4.2.6.jar`).

## Мелочи, которые всегда нужны

- `/give @s minecraft:netherite_pickaxe{Enchantments:[{id:"minecraft:silk_touch",lvl:1}]}`
- `/effect give @s minecraft:night_vision 9999 0 true`
- `/gamemode spectator` — пролететь сквозь камень и увидеть жилы глазами.
- `/data get entity @s Pos` — точные координаты, если F3 выключен.
