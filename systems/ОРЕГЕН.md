## Куда идём — каким это будет на 100 %

Главный генератор руды — **AdLods**. Он оставляет игроку два читаемых способа добычи: искать обычную россыпь для постоянной ранней добычи и находить редкие крупные месторождения для экспедиций; сигнальные лампы финдера уже отличают крупную компоненту от обычной россыпи. Россыпь и месторождения ограничиваются раздельно конфигурацией AdLods: для ванильных руд — режимом `VANILLA`/`CUSTOM`/`NONE` и параметрами собственной генерации, для месторождений — отдельными определениями состава, высоты, измерения и редкости; внешние источники режутся точечными biome-modifier'ами, когда именно они ломают выбранную лестницу.

Древние обломки подчинены той же бюджетной схеме, что и остальные базовые руды: сравнивается лишь добываемая полоса, обычная генерация не должна заменяться бесконтрольной жилой, а редкая крупная жила может компенсировать отсутствие обычной. `gas_pocket` выключен: он требовал блоки отсутствующего компаньона и не является частью маршрута игрока.

Из исходного гео-стека вырезаны **Geolosys**, Regional Ore Veins, Custom Ore Veins, Create Geo-Resonance, Create Ore Excavation+ и createoreexcavation. Причина не вкусовая: Geolosys умеет убрать ванильные фичи только общим списком и не умеет одновременно точечно отбирать модовые руды, сохранять урезанную биомную россыпь и давать редкие большие жилы; AdLods даёт эти рычаги по руде. Решение окончательно принято в `OPEN.md` §1.227 и применено коммитом `15bef75`.

Каталог структур остаётся контрольной картой мира: владелец может получить актуальный список и команды поиска, затем принять решения о сохранении, вырезании и расстояниях между структурами. Это не обещание, что любой уже зарегистрированный объект остаётся в релизе.

**Скоуп не решён:** окончательная настройка состава и частоты части AdLods-жил, восстановление полезных индикаторов, поведение пустых тегов и судьба руды Twilight Forest ждут соответственно `OPEN.md` §1.244, §1.239 и §1.240; объединение трёх финдеров — отдельный выбор в `OPEN.md` §1.245.

## На чём это стоит

- **AdLods — окончательный генератор, Geolosys и альтернативный гео-стек вырезаны.** `OPEN.md` §1.227.
- **Режим `CUSTOM` у AdLods ставит собственную фичу и одновременно убирает соответствующую ванильную, поэтому двойной генерации нет.** `agents/progression/2026_08_25_ADLODS_CUSTOM_VS_REMOVED_VANILLA.md`.
- **Россыпь и месторождения — разные поверхности конфигурации; индекс мира умеет читать обе.** `agents/tools/2026_08_25_ADLODS_INDEX_INTAKE.md`.
- **Газовый карман исключён из активного генератора; переназначать его под обломки нельзя.** Закрытое решение и доказательство — `OPEN.md` §5, строка «gas_pocket выключен».
- **Финдер различает крупную компоненту тревожными лампами, но не получает координаты именно этой компоненты.** `TODO.md`, блок «ОРЕГЕН — ПРИМЕНЁН».
- **Каталог структур — воспроизводимая выгрузка из зарегистрированных данных, а не вручную составленный список.** `claudework/technicalities/ВОРЛДГЕН_КАТАЛОГ.md`; генератор — `dump_worldgen_catalog.py`.
- **Модовую россыпь нельзя безопасно балансировать одной редкостью, пока не закрыты реальные источники и теги.** `agents/worldgen/2026_08_25_MODDED_METAL_SCATTER_AND_RARITY.md`; вопрос владельца — `OPEN.md` §1.246.

## Чем проверить

Сначала получить актуальный корень каждой копии, а не подставлять путь вручную:

```powershell
python bountiful_wizards_REMAKE/tools/paths.py --master
python bountiful_wizards_REMAKE/tools/paths.py --client
python bountiful_wizards_REMAKE/tools/paths.py --server
```

Проверить, что применён именно выбранный набор изменений:

```powershell
git show --stat 15bef75
```

Проверить, что индексатор читает обе поверхности AdLods и что регрессия не вернулась:

```powershell
python -m pytest bountiful_wizards_REMAKE/tests/test_adlods_index_intake.py
```

Напечатать актуальные режимы ванильных руд и активность месторождений, подставив корень, который вывела первая команда:

```powershell
$master = python bountiful_wizards_REMAKE/tools/paths.py --master
Get-ChildItem "$master/config/adlods/VanillaOres" -Filter '*.cfg' | ForEach-Object { Select-String -Path $_.FullName -Pattern 'S:generation=' }
Get-ChildItem "$master/config/adlods/Deposits" -Filter '*.cfg' | ForEach-Object { Select-String -Path $_.FullName -Pattern 'B:enabled=' }
```

Пересобрать проверочную копию каталога структур во временный файл и убедиться, что у нужных объектов есть команда поиска:

```powershell
$catalog = Join-Path ([System.IO.Path]::GetTempPath()) 'worldgen-catalog.md'
python bountiful_wizards_REMAKE/tools/dump_worldgen_catalog.py --out $catalog
Get-Content $catalog
```
