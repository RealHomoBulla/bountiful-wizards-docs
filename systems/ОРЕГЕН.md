# ОРЕГЕН

> **Главный мод:** AdLods · **Готовность: 40 %**
> **Больше всего мешает:** не выбран смысл строгой лестницы редкостей при нескольких живых источниках руд.
> **Ждёт твоего слова:** 1 вопрос · **Проверить в игре:** 1 программа fresh-world.

## 1. Куда идём — каким это будет на 100 %

AdLods остаётся контролируемой поверхностью для ванильных жил и крупных месторождений: игрок видит обычную добычу и экспедиционную, а пак управляет включением и параметрами именно из `config/adlods/`. Внешние источники не объявляются автоматически заменёнными: до решения о лестнице редкостей они учитываются по реальным registry/resource path и меняются только точечно.

Целевой скоуп **не решён**: строгая лестница во всех биомах либо только в обычных биомах, либо сознательный отказ от неё — `OPEN.md` §1.325. Поэтому страница не обещает единый глобальный объём руды и не выдаёт название feature за её фактический block-registry target: `galosphere:ore_silver_*` в архиве кладёт `galosphere:palladium_ore` / `galosphere:deepslate_palladium_ore`. С 2026-08-28 Block Swap превращает именно эти попытки генерации в обычные `minecraft:stone` / `minecraft:deepslate`, а технические `palladium_*` id готовых предметов остаются для совместимости миров и видимо называются Silver/«серебряная» через KubeJS lang override.

Избыточные или неподтверждённые утверждения прежнего дизайна вырезаны из этой страницы. Для алмазной лоды приведены только живые параметры `diamond.cfg`: веса 7/3, размер 8–11 и rarity 6; потолок добычи без fresh-world замера не заявлен.

**Готовность раздела: 40 %** — шкала зафиксирована здесь: «готово» даёт весь вес, «частично» даёт половину веса только когда статическая диагностика и точный вход существуют, «нет» даёт ноль. Расчёт: `20 + (20 × 0.5) + (10 × 0.5) + 5 = 40` из 100. Это готовность орегена в паке, а не процент строк или недельного плана.

### Что не начато вообще

- Fresh-world замер финальных block-registry id после генерации: отдельно обычные биомы, холодные/горные, `minecraft:ice_spikes` и `galosphere:crystal_canyons`; без него нет честного units-per-chunk итога.
- Применение или замена 133 неразрешимых indicator selectors.
- Финальная политика для пересечений AdLods, native features и create_rns после решения о лестнице.

## 4. 🔴 Что сломано

- **133 из 216 живых строк `S:circles` в 30 deposit-конфигах используют namespaces `silentgems`, `botania` или `surfacesamples`, которых нет в строгом `META-INF/mods.toml` listing ни client, ни server.** Это доказанный неразрешимый вход конфигурации. Статический разбор не заменяет запуск: его фактический load/runtime эффект надо принять в fresh-world программе, а исправление пока не применено.
- **Строгая глобальная лестница редкостей не доказана.** В jar есть дополнительные C&C и Galosphere source paths, а create_rns имеет structure assets при нулевых configured/placed-feature и Forge-biome-modifier JSON в обеих установленных версиях. Это не числовой verdict о добыче, но достаточно, чтобы не считать одну AdLods `rarity` глобальным контролем.

## 6. На чём это стоит

- `config/adlods-common.toml` содержит `disabledFeatures = []`: это точный факт о данном переключателе, поэтому AdLods сам не доказывает удаление чужих источников. `docs/TRAPS.md` §47; перепроверено 2026-08-28.
- В registry/resource listing AdLods есть 4 configured features и 4 Forge biome modifiers; create_rns в client 1.3.1 и server 1.2.4 не имеет JSON в этих трёх registries, но server jar содержит `data/create_rns/structures/ore_deposit_{small,medium,large}.nbt`.
- `galosphere:ore_silver_small` и `galosphere:ore_silver_large` — **configured-feature registry ids**; их targets — **block-registry ids** `galosphere:palladium_ore` и `galosphere:deepslate_palladium_ore`. Block Swap превращает эти block ids в обычный камень при новой генерации: это удаление лишнего источника, не перенос его в серебро. Сохраняемые `palladium_*` предметы и декор получает Silver/«серебряная» через `kubejs/assets/galosphere/lang/{en_us,ru_ru}.json`.
- Exact: hashes, config tokens, registry listings и количество selector. Direction only: объединённый выход руды на chunk и порядок по биомам; их нельзя получить точной суммой из `rarity`, size или structure spacing без fresh-world замера.

## 7. Чем проверить

Получить реальные корни копий, не записывая их руками:

```powershell
python bountiful_wizards_REMAKE/tools/paths.py --master
python bountiful_wizards_REMAKE/tools/paths.py --client
python bountiful_wizards_REMAKE/tools/paths.py --server
```

Проверить живой переключатель и конфигурации AdLods; нормой для текущего состояния является пустой `disabledFeatures` и disabled `gas_pocket`:

```powershell
$master = python bountiful_wizards_REMAKE/tools/paths.py --master
Select-String -Path "$master/config/adlods-common.toml", "$master/config/adlods/Deposits/gas_pocket.cfg" -Pattern 'disabledFeatures|B:enabled'
```

Пересобрать контрольный каталог (регистрация не равна генерации):

```powershell
$catalog = Join-Path ([System.IO.Path]::GetTempPath()) 'worldgen-catalog.md'
python bountiful_wizards_REMAKE/tools/dump_worldgen_catalog.py --out $catalog
Get-Content $catalog -TotalCount 20
```

Перед применением indicator patch считать именно фиксированное состояние: норма после отдельной правки — 30 файлов, 83 circles и только `minecraft`/`adfinders`; текущий broken input намеренно этот критерий не проходит.

```powershell
@'

from pathlib import Path

    files += 1; inside = False
```
