## Куда идём — каким это будет на 100 %

Iron’s Spellbooks — единая магическая система. Игрок получает `can_magic`, открывает рабочие места, выбирает школы и поднимает редкость через один прогрессионный маршрут. `irons_restrictions` проверяет изучение и редкость при касте, `unraveling_spells` ограничивает число школ, а KubeJS держит материальную лестницу чернил и орбов.

Дешёвые сборочные маршруты базового и школьных орбов, котловая лестница чернил и Goety вырезаны: они обходили гейт либо не проходили загрузку. Объём первой релизной ветки Puffish остаётся `OPEN.md` §1.182; `TODO.md` `MAGIC-SYSTEM-FINISH` сводит источник изучения, начальный набор и редкость.

## Чем проверить

```powershell
$roots=@((python bountiful_wizards_REMAKE/tools/paths.py --master).Trim(),(python bountiful_wizards_REMAKE/tools/paths.py --client).Trim(),(python bountiful_wizards_REMAKE/tools/paths.py --server).Trim())
$roots | ForEach-Object { Select-String (Join-Path $_ 'config/unraveling_spells-common.toml') -Pattern '^\s*max_schools\s*=' }
$roots | ForEach-Object { Get-FileHash (Join-Path $_ 'kubejs/server_scripts/16_Ironspells_Block.js') -Algorithm SHA256 }
```

Норма: везде `max_schools = 4`, а три hash `16_Ironspells_Block.js` одинаковы. Runtime-приёмка выполняется только по корневому чеклисту.
