## Чем проверить

```powershell
python bountiful_wizards_REMAKE/tools/paths.py --client
python bountiful_wizards_REMAKE/tools/paths.py --server
```

Команды должны назвать реальные стороны; затем можно сверить, что RNS-артефакт всё ещё
лежит на обеих сторонах. Наличие JAR не считать приёмкой запуска.

```powershell
$master = python bountiful_wizards_REMAKE/tools/paths.py --master
$hits = rg -n -i -m 100 'create_rns|bw_rns|mine[_ -]?head|deposit[_ -]?scanner' `
  "$master/kubejs" "$master/config/ftbquests" 2>$null
if ($LASTEXITCODE -eq 0) { $hits } else { 'NO_AUTHORED_RNS_OR_MINE_HEAD_OR_SCANNER_REFERENCES_IN_MASTER_KUBEJS_OR_FTBQUESTS' }
```

Нормально, пока §1.289 не решён: печатается строка `NO_AUTHORED…`. Если появится reference, это новый
authored-контент, требующий скоупа и проверки загрузки.

```powershell
$master = python bountiful_wizards_REMAKE/tools/paths.py --master
Get-ChildItem "$master/kubejs/data/bw_lode" -Recurse -File -Filter *.json |
  ForEach-Object { Get-Content -Raw -LiteralPath $_.FullName | ConvertFrom-Json | Out-Null }
```

Нормально: команда завершается без ошибки разбора. Это утверждает только валидный JSON;
она не заменяет Forge-загрузку или генерацию мира.
