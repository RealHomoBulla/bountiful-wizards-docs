# Create — 57 %

**Как будет на 100 %.** Create — кинетический хребет пака: ты ставишь источник вращения, тянешь валы и ленты и собираешь первые фабрики.
Сложные детали делает сборочная линия Create, а рядом всегда есть дорогой ручной путь. Вращение переходит в FE через Crafts & Additions и New Age.
Пневмотрубы возят предметы только через регулятор с FE. Вращающимся узлам нужна смазка, и ты её автоматизируешь. Каждый аддон имеет роль, рецепт и конфиг.

**Сделано и проверено тобой**
- Ядро Create 6.0.8 на клиенте и сервере, цепь Create пройдена
- Звук пневмотруб; корзина Farmer's Delight больше не роняет игру
- Create Package (сеть AE2, дистрибьютор) и планер cbbees — приняты

**Сделано, ждёт твоей проверки**
- Б232, Б302 — пневморегулятор после переделки
- Б395 — смазка и износ: уровень масла, нагрузка +50 % / +100 %, ремонт ремкомплектом
- Б301 — Steam Powered на сервере, Henry убран
- Б245, S44 — страж вентилятора и инфьюзер
