## Куда идём — каким это будет на 100 %

**Wares** — не второй магазин и не альтернативная касса. Это отдельный маршрут для крупных тематических поставок: игрок получает договор, производит заметную партию нужного материала, упаковывает и сдаёт её через delivery table/Packager либо вручную, а затем получает заранее определённую награду, согласованную с прогрессией. Первый контур — два пробных производственных заказа на `create:shaft`: один на одну большую партию, второй — на следующую по объёму ступень. Их точные объём, награда и источник договора берутся из одной ценовой базы, а не из stock-таблицы мода.

Договоры authorятся datapack-таблицами `kubejs/data/wares/loot_tables/agreement/...`; при необходимости награда за завершение привязывается только к подтверждённому событию Wares. Игрок видит один понятный выбор: взять большой заказ, сделать именно тематическую продукцию и закрыть поставку. Повторяемая продажа сырья за изумруды, отдельная валюта Wares и награды, обходящие доски Bountiful, не выпускаются.

Из оригинала вырезается stock cash-out: сейчас Wares способен просить обычные фермерские товары и платить vanilla-изумрудами без доски, таймера или репутационного контура. Остаются сами доставка, коробки, Packager и склады — это полезная физическая форма опта, а не новый рынок.

## Чем проверить

```powershell
# Runtime Wares на обеих игровых сторонах: нормой являются одинаковые имя и SHA-256.
$packPaths = python bountiful_wizards_REMAKE/tools/paths.py
$client = (($packPaths | Select-String '^CLIENT\s').Line -replace '^CLIENT\s+','')
$server = (($packPaths | Select-String '^SERVER\s').Line -replace '^SERVER\s+','')
Get-ChildItem "$client\mods", "$server\mods" -File | Where-Object Name -match '(?i)wares' |
  Get-FileHash -Algorithm SHA256

# Authored override появится только полным набором: до пилота команда печатает пустой результат.
Get-ChildItem bountiful_wizards_REMAKE/kubejs/data/wares/loot_tables/agreement -Recurse -File -ErrorAction SilentlyContinue

# Перед выпуском JSON обязан быть валидным, а полный набор не должен оставить stock emerald output.
Get-ChildItem bountiful_wizards_REMAKE/kubejs/data/wares/loot_tables/agreement/village -File |
  ForEach-Object { Get-Content $_ -Raw | ConvertFrom-Json | Out-Null }
```

Нормой выпуска станет: оба технических smoke-gate пройдены в отдельной test-copy, authored-таблицы закрывают весь stock cash-out, два shaft-договора имеют доказанные вход/награду, и один полный delivery-loop подтверждён в игре.
