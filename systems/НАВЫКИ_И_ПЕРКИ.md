## Куда идём — каким это будет на 100 %

Главная система личного развития — одно дерево **Puffish Skills** в неймспейсе `arcane_engineer`. Игрок получает очки за понятные действия, выбирает профильные возможности и видит, почему следующий узел закрыт; FTB Quests остаётся картой исследования и фаз, а не вторым деревом способностей. Дерево не создаёт параллельной магической экономики: оно открывает способы играть — например, личное движение, доступ к информации или специальные действия — и каждую награду можно проверить на серверной либо клиентской границе.

Это именно одно дерево: второй набор категорий означал бы второй бесплатный бюджет очков. Amblewood не возвращается (`OPEN.md` §1.157): у него не было точки входа Puffish, а восстановление дало бы вторую, не выбранную систему. Passive Skill Tree также не входит в пак: его дважды отвергли как второе дерево, во второй раз владелец прямо сказал, что мод был только для проверки.

У Puffish уже есть собственные источники опыта действий и защита от фарма; значит маршрут «добываешь блоки — растёт горное развитие» можно собрать изменением нашего datapack, без нового мода. Но целевой объём и темп ещё не выбраны: `OPEN.md` §1.182 оставляет выбор между малой первой веткой и полной; до него эта страница не обещает окончательный список узлов или скорость их открытия.

## Чем проверить

- `python bountiful_wizards_REMAKE/tools/paths.py` — сначала печатает актуальные корни master, сервера и клиента; перед сравнением не подставлять путь вручную.
- `rg --files bountiful_wizards_REMAKE/kubejs/data/arcane_engineer/puffish_skills` — должны быть видны точка входа и данные категории «Пути».
- ```powershell
  $roots = @((python bountiful_wizards_REMAKE/tools/paths.py --master).Trim(), (python bountiful_wizards_REMAKE/tools/paths.py --server).Trim(), (python bountiful_wizards_REMAKE/tools/paths.py --client).Trim())
  $rel = @('config.json','categories/paths/category.json','categories/paths/connections.json','categories/paths/definitions.json','categories/paths/skills.json')
  foreach ($root in $roots) { foreach ($file in $rel) { Get-FileHash (Join-Path $root "kubejs/data/arcane_engineer/puffish_skills/$file") -Algorithm SHA256 } }
  ```
  — для каждого одноимённого файла хэш должен совпасть во всех трёх копиях.
- ```powershell
  $server = (python bountiful_wizards_REMAKE/tools/paths.py --server).Trim()
  rg -n "\[puffish_skills\].*arcane_engineer.*loaded successfully" "$server/logs/latest.log"
  ```
  — нормой является успешная загрузка datapack, а не пустой результат поиска.
- `Test-Path bountiful_wizards_REMAKE/kubejs/data/arcane_engineer/puffish_skills/categories/paths/experience.json` — сейчас ожидается `False`; после выбора маршрута опыта файл и его anti-farm настройки должны стать отдельным предметом проверки.
- ```powershell
  $client = (python bountiful_wizards_REMAKE/tools/paths.py --client).Trim()
  $jar = (Get-ChildItem (Join-Path $client 'mods') -Filter 'puffish_skills*.jar').FullName
  Add-Type -AssemblyName System.IO.Compression.FileSystem; $zip = [IO.Compression.ZipFile]::OpenRead($jar)
  $zip.Entries | Where-Object FullName -match '/experience/source/builtin/.+ExperienceSource\.class$|AntiFarmingPer(Chunk|Entity)\.class$' | ForEach-Object FullName; $zip.Dispose()
  ```
  — выводит доступные в установленном джарнике источники действий и оба ограничителя фарма; это проверка API до проектирования опыта, не доказательство игрового баланса.
