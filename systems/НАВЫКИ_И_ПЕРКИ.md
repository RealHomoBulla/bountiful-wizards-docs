# Навыки и перки

> **Главный мод:** Puffish Skills — наше будущее авторское дерево · **Готовность: 28 %**
>
> **Больше всего мешает:** не выбран объём первой настоящей ветки (`OPEN.md` §1.182); авторское дерево пока обратимо выключено.
>
> **Ждёт твоего слова:** 4 вопроса (`OPEN.md` §§1.182, 1.398, 1.401–1.402) · **Проверить в игре:** `SKILL-GAME-01` · **Статика:** `SKILL-STATIC-01`

## Куда идём — каким это будет на 100 %

Главная система личного развития — одно авторское дерево **Puffish Skills** в
неймспейсе `arcane_engineer`. Игрок получает очки за понятные действия, открывает
профильные возможности и видит, почему следующий узел закрыт; FTB Quests остаётся
картой исследования и фаз, а не вторым деревом способностей. `specialities`
(Skill Proficiencies) остаётся отдельным живым фоном со своей прокачкой, пока его
влияние на бой не принято по `OPEN.md` §1.402.

Движение принадлежит **ParCool**, а `arcane_engineer:paths` — остальным авторским
возможностям: элементы ParCool из Puffish удалены по `OPEN.md` §§1.305–1.306.
Amblewood не возвращается: отвеченное B12 исполнено внешним архивированием, а
исходники `amblewood_skills` в live-копиях пусты (`OPEN.md` §1.400; подробности
исполнения — в `TODO.md`). Второе дерево не создаём, чтобы не выдавать игроку
параллельный бесплатный бюджет очков.

## 🔴 Что сломано

- 🔧 **ParCool player layer не равен seed/world layer.** В live UUID-записи
  `allow_infinite_stamina=true`, а seed и world содержат `false`. Это статическое
  расхождение; влияние на игрока не объявляется, пока не выполнен `SKILL-GAME-01`.

Других живых runtime-дефектов эта page-only сверка не утверждает: пустой Puffish
профиль и отсутствие XP — текущие границы незавершённой системы, а не повод
переоткрывать решённые решения.

## В работе

Авторское дерево не реализуется до решения объёма в `OPEN.md` §1.182. Исполняемая
очередь живёт только в [`TODO.md`](../agents/registers/TODO.md); эта страница не
дублирует план. `SKILL-GAME-01` остаётся открытым до настоящей проверки в игре.

## На чём это стоит

- Голый `puffish_skills` остаётся движком будущего немагического дерева; второй
  авторский namespace не восстанавливается — `OPEN.md` §§1.157, 1.182.
- B12 по `amblewood_skills` — внешнее архивирование, а не новый owner choice;
  live-источники пусты — `OPEN.md` §1.400 и соответствующая строка `TODO.md`.
- ParCool владеет движением, Puffish не дублирует его элементы — `OPEN.md`
  §§1.305–1.306.
- Текущая карта модулей и слой владения —
  [`MOD_SURFACE.md`](../agents/knowledge/skills_perks/MOD_SURFACE.md); решения и
  границы приёмки — [`DECISIONS_AND_VERIFICATION.md`](../agents/knowledge/skills_perks/DECISIONS_AND_VERIFICATION.md#short-evidence-commands).

## Чем проверить

Команды ниже начинаются из корня репозитория и явно разделены по оболочке.

### Linux / bash

```bash
MASTER="$(python3 bountiful_wizards_REMAKE/tools/paths.py --master)"
REPO="$(python3 bountiful_wizards_REMAKE/tools/paths.py --repo)"
SERVER="$(python3 bountiful_wizards_REMAKE/tools/paths.py --server)"
CLIENT="$(python3 bountiful_wizards_REMAKE/tools/paths.py --client)"

# Roots and live ParCool generation; filter out the compatibility add-on.
find "$SERVER/mods" "$CLIENT/mods" -maxdepth 1 -type f \
  -name 'ParCool-1.20.1-*.jar' ! -name '*Compatibility*' -printf '%p\n' | sort
sha256sum "$SERVER/mods/ParCool-1.20.1-3.4.3.3.jar" \
  "$CLIENT/mods/ParCool-1.20.1-3.4.3.3.jar"

# Static tree state: expect true for all three files and exit 0.
jq -e '.categories == []' \
  "$MASTER/kubejs/data/arcane_engineer/puffish_skills/config.json" \
  "$SERVER/kubejs/data/arcane_engineer/puffish_skills/config.json" \
  "$CLIENT/kubejs/data/arcane_engineer/puffish_skills/config.json"
for root in "$MASTER" "$SERVER" "$CLIENT"; do
  jq 'length' "$root/kubejs/data/arcane_engineer/puffish_skills/categories/paths/definitions.json" \
     "$root/kubejs/data/arcane_engineer/puffish_skills/categories/paths/skills.json"
  jq '[.normal.bidirectional[], .normal.unidirectional[]] | length' \
     "$root/kubejs/data/arcane_engineer/puffish_skills/categories/paths/connections.json"
  jq '.starting_points' "$root/kubejs/data/arcane_engineer/puffish_skills/categories/paths/category.json"
  test ! -e "$root/kubejs/data/arcane_engineer/puffish_skills/categories/paths/experience.json"
done

# Hooks and static ParCool layers; no gameplay result is inferred.
sed -n '1,20p' "$MASTER/kubejs/server_scripts/33_Perk_Projection.js"
rg -n 'PACK_PUFFISH_PERKS_ENABLED' \
  "$MASTER/kubejs/client_scripts/98_Perk_Attuned_Sight.js"
rg -n 'limitation_imposed|permit_Roll|permit_Tap|permit_Dodge|allow_infinite_stamina' \
  "$MASTER/defaultconfigs/parcool-server.toml" \
  "$SERVER/world/serverconfig/parcool-server.toml" \
  "$SERVER/world/serverconfig/parcool/limitations/parcool/individual/6a98ac0a-25c6-3aca-955c-4de9678bcda8.json"

# Datapack load is not category activation: inspect both logs and the config.
rg -n 'arcane_engineer|\[perks\]' "$SERVER/logs/latest.log" "$CLIENT/logs/latest.log"

# Ownership census: all four should be absent from MASTER and present on deployed roots.
for rel in config/puffish_skills/config.json config/attributeslib.cfg \
           config/jumpoverfences-client.toml defaultconfigs/xptome-server.toml; do
  printf '%s\n' "$rel"
  for root in "$MASTER" "$SERVER" "$CLIENT"; do test -e "$root/$rel"; printf '%s=%s\n' "$root" "$?"; done
done

nl -ba "$REPO/claudework/ИГРОВОЙ_ЧЕКЛИСТ.md" | sed -n '262,267p'
python3 bountiful_wizards_REMAKE/tools/check_systems_readiness_sync.py
```

Норма: основной ParCool — 3.4.3.3 с одинаковым SHA-256; `categories: []`,
15 definitions/15 skills, пустые connections, 20 starting points и отсутствие
`experience.json`; client hook `false`, server projection — stub. Строка о
`Data pack ... loaded successfully` доказывает загрузку datapack, но не активную
категорию; `SKILL-STATIC-01` и `SKILL-GAME-01` сверяются с чеклистом, а игра
остаётся единственным способом закрыть последний.

### PowerShell

```powershell
$master = python bountiful_wizards_REMAKE/tools/paths.py --master
$repo   = python bountiful_wizards_REMAKE/tools/paths.py --repo
$server = python bountiful_wizards_REMAKE/tools/paths.py --server
$client = python bountiful_wizards_REMAKE/tools/paths.py --client

Get-ChildItem (Join-Path $server 'mods') -Filter 'ParCool-1.20.1-*.jar' |
  Where-Object { $_.Name -notlike '*Compatibility*' } | Select-Object -ExpandProperty FullName
Get-FileHash (Join-Path $server 'mods/ParCool-1.20.1-3.4.3.3.jar'),
             (Join-Path $client 'mods/ParCool-1.20.1-3.4.3.3.jar') -Algorithm SHA256

$configs = @(
  (Join-Path $master 'kubejs/data/arcane_engineer/puffish_skills/config.json'),
  (Join-Path $server 'kubejs/data/arcane_engineer/puffish_skills/config.json'),
  (Join-Path $client 'kubejs/data/arcane_engineer/puffish_skills/config.json')
)
$configs | ForEach-Object { Get-Content $_ -Raw | ConvertFrom-Json | Select-Object -ExpandProperty categories }
Select-String -Path (Join-Path $master 'kubejs/client_scripts/98_Perk_Attuned_Sight.js') -Pattern 'PACK_PUFFISH_PERKS_ENABLED'
Get-Content (Join-Path $master 'kubejs/server_scripts/33_Perk_Projection.js') -TotalCount 20

Select-String -Path (Join-Path $server 'logs/latest.log'), (Join-Path $client 'logs/latest.log') -Pattern 'arcane_engineer|\[perks\]'
Select-String -Path (Join-Path $master 'defaultconfigs/parcool-server.toml'),
  (Join-Path $server 'world/serverconfig/parcool-server.toml'),
  (Join-Path $server 'world/serverconfig/parcool/limitations/parcool/individual/6a98ac0a-25c6-3aca-955c-4de9678bcda8.json') `
  -Pattern 'limitation_imposed|permit_Roll|permit_Tap|permit_Dodge|allow_infinite_stamina'

$checklist = Join-Path $repo 'claudework/ИГРОВОЙ_ЧЕКЛИСТ.md'
Get-Content $checklist | Select-Object -Skip 261 -First 6
python bountiful_wizards_REMAKE/tools/check_systems_readiness_sync.py
```

Норма та же: хэш и static values must match the Linux probe; successful datapack
load is not an active-category result, and `SKILL-GAME-01` remains open until a
fresh-profile game check is recorded.
