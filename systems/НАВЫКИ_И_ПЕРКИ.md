## Чем проверить

Команды запускаются из корня репозитория; ниже два варианта — для bash и для PowerShell.

### Команды для Linux (bash)

```bash
MASTER="$(python3 bountiful_wizards_REMAKE/tools/paths.py --master)"
REPO="$(python3 bountiful_wizards_REMAKE/tools/paths.py --repo)"
SERVER="$(python3 bountiful_wizards_REMAKE/tools/paths.py --server)"
CLIENT="$(python3 bountiful_wizards_REMAKE/tools/paths.py --client)"

# Корни и живая версия ParCool; аддон совместимости отфильтрован.
find "$SERVER/mods" "$CLIENT/mods" -maxdepth 1 -type f \
  -name 'ParCool-1.20.1-*.jar' ! -name '*Compatibility*' -printf '%p\n' | sort
sha256sum "$SERVER/mods/ParCool-1.20.1-4.0.1.5.jar" \
  "$CLIENT/mods/ParCool-1.20.1-4.0.1.5.jar"

# Инженерия: живой аддон и его числа (26.09)
ls "$SERVER/mods" "$CLIENT/mods" | grep skill_perks
sha256sum "$SERVER/mods/bountiful_skill_perks-0.4.4-test-forge-1.20.1.jar" \
          "$CLIENT/mods/bountiful_skill_perks-0.4.4-test-forge-1.20.1.jar"
grep -nE 'Level =' "$MASTER/defaultconfigs/bountiful_skill_perks-server.toml"
grep -nE 'Level =' "$SERVER/world/serverconfig/bountiful_skill_perks-server.toml"   # в мире есть и 8 ключей перков
md5sum "$MASTER/kubejs/server_scripts/loot/07_Specialities_Books.js" \
       "$SERVER/kubejs/server_scripts/loot/07_Specialities_Books.js" \
       "$CLIENT/kubejs/server_scripts/loot/07_Specialities_Books.js"                # три одинаковых хэша

# Статика снятого дерева Puffish: в мастере каталога arcane_engineer нет с 30.09 (2861ba3e5),
# поэтому MASTER-строки ниже печатают «No such file» — это норма (критерий нормы = ровно эти отказы; строки SERVER/CLIENT проверяют только старую копию); клиент: kubejs\data\arcane_engineer\puffish_skills\categories\paths пуст (0 файлов), поэтому jq по этому пути на клиенте не отработает; сервер не проверен (на этом ПК не найден).
jq -e '.categories == []' \
  "$MASTER/kubejs/data/arcane_engineer/puffish_skills/config.json" \
  "$SERVER/kubejs/data/arcane_engineer/puffish_skills/config.json" \
  "$CLIENT/kubejs/data/arcane_engineer/puffish_skills/config.json"
for root in "$MASTER" "$SERVER" "$CLIENT"; do
  jq 'length' "$root/kubejs/data/arcane_engineer/puffish_skills/categories/paths/definitions.json" \
     "$root/kubejs/data/arcane_engineer/puffish_skills/categories/paths/skills.json"
  jq '[.normal.bidirectional[], .normal.unidirectional[]] | length' \
     "$root/kubejs/data/arcane_engineer/puffish_skills/categories/paths/connections.json"
  jq '.starting_points' "$root/kubejs/data/arcane_engineer/puffish_skills/categories/paths/category.json"
  test ! -e "$root/kubejs/data/arcane_engineer/puffish_skills/categories/paths/experience.json"
done

# Крючки и статические слои ParCool; об игре отсюда ничего не следует.
sed -n '1,20p' "$MASTER/kubejs/server_scripts/33_Perk_Projection.js"
rg -n 'PACK_PUFFISH_PERKS_ENABLED' \
  "$MASTER/kubejs/client_scripts/98_Perk_Attuned_Sight.js"
rg -n 'limitation_imposed|permit_Roll|permit_Tap|permit_Dodge|allow_infinite_stamina' \
  "$MASTER/defaultconfigs/parcool-server.toml" \
  "$SERVER/world/serverconfig/parcool-server.toml"
# Личный слой: ожидается "imposed": false (решение владельца §1.758-A, 22.09).
jq '.imposed' "$SERVER/world/serverconfig/parcool/limitations/parcool/individual/6a98ac0a-25c6-3aca-955c-4de9678bcda8.json"

# Загрузка датапака — не включение категории: смотреть оба лога и конфиг.
rg -n 'arcane_engineer|\[perks\]' "$SERVER/logs/latest.log" "$CLIENT/logs/latest.log"

# Кто владеет: все четыре файла отсутствуют в MASTER и есть на выложенных копиях.
for rel in config/puffish_skills/config.json config/attributeslib.cfg \
           config/jumpoverfences-client.toml defaultconfigs/xptome-server.toml; do
  printf '%s\n' "$rel"
  for root in "$MASTER" "$SERVER" "$CLIENT"; do test -e "$root/$rel"; printf '%s=%s\n' "$root" "$?"; done
done

grep -n 'SKILL-' "$REPO/claudework/ИГРОВОЙ_ЧЕКЛИСТ.md"
grep -n 'SKILL-STATIC-01' "$REPO/claudework/agents/checklists/2026_09_21_TERMINAL_CHECKS.md"
python3 bountiful_wizards_REMAKE/tools/check_systems_readiness_sync.py
```

на сервере и клиенте; личной записи в ParCool 4.x нет (проверить после выкладки); `schematicannonLevel = 10`, `beesLevel = 30`, `attunedSightLevel = 8` (мастер; было 25);
книга знаний — три одинаковых md5; статика Puffish — только на старых копиях (в мастере снята); `categories: []`, 15 определений и 15 навыков, связей нет, 20 стартовых очков,
`experience.json` нет; клиентский крючок `false`, серверный скрипт — заглушка. Строка `Data pack ... loaded successfully`
доказывает загрузку датапака, но не включённую категорию. `SKILL-STATIC-01` и `SKILL-GAME-01` сверяются с чеклистом;
второй закрывает только игра.

### Те же команды для PowerShell

